Authorization code flow (PKCE required)

1. Redirect the user to
{{ base_url }}/oauth/authorize?response_type=code
  &client_id=…&redirect_uri=…&scope=read%20write&state=…
  &code_challenge=BASE64URL(SHA256(verifier))&code_challenge_method=S256

2. Exchange the code
curl -u CLIENT_ID:CLIENT_SECRET {{ base_url }}/oauth/token \
  -d grant_type=authorization_code -d code=… \
  -d redirect_uri=… -d code_verifier=…

3. Call the API
curl {{ base_url }}/api/v1/me -H "Authorization: Bearer aal_at_…"

4. Refresh (rotates both tokens)
curl -u CLIENT_ID:CLIENT_SECRET {{ base_url }}/oauth/token \
  -d grant_type=refresh_token -d refresh_token=aal_rt_…

Access tokens last 1 hour, refresh tokens 60 days. Revoke with POST /oauth/revoke (RFC 7009). Metadata: /.well-known/oauth-authorization-server.
